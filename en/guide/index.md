# Introduction {#introduction}


:::tip
Developing a desktop widget is essentially developing a front-end webpage.
  :::

**If you want to develop a simple widget (without complex operational logic) and don't want to read the documentation, you can implement your idea with Vue, and then send me the `result screenshots` and the `source code link` of your page, and I will help you finish the rest of the work.**


Widget Hub are currently in a very early stage, with many features needing to be developed, documentation to be written, and bugs to be fixed. The current documentation is still in draft stage, only covering the basic widget development process. If you have any questions, feel free to ask in the QQ group at any time.
