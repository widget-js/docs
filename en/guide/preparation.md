## Enable Developer Mode

#### After opening the desktop widget client, right-click the tray icon in the bottom right corner, then long-press the GitHub icon for 5 seconds to enable Developer Mode

![Tray Setting Menu](/assets/guide/enable-dev.png)

#### Once enabled, right-clicking on a widget will pop up the DevTools menu

:::tip
DevTools is consistent with Chrome DevTools, where you can debug web pages.
  :::
![Tray Setting Menu](/assets/guide/devtools.png)
