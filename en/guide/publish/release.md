# Publish Widget Package

1. Send the packaged `widget.zip` file to the email: `rtugeek@gmail.com`.
2. Please indicate the widget name and author information in the email title, and you can briefly introduce the widget functionality in the body.
3. After passing the review, the widget package will be open for search on the platform and visible to all users.
4. The review is generally completed within 1-3 working days, and the results will be replied via email.

> Notes:
> - Please ensure the `widget.zip` package contains the complete widget code and necessary documentation.
> - Widgets must comply with platform regulations and are prohibited from containing malicious code or infringing content.
> - If you have any questions, you can consult via email.
